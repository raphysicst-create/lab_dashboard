# 탐구 과정 검토

기존 검색기의 활동 ID를 기준으로 해당 판본과 학생 지면을 찾는다. 세 파일을 합하면 공개 활동 전체가 된다.

| 검토 파일 | 대상 | 활동 |
|---|---|---:|
| `legacy.json` | 기존 중학교 자료 5개 출판사·저자 표기 | 454 |
| `middle.json` | 중학교 지학사·YBM | 408 |
| `high.json` | 고1 통합과학 1·2 | 414 |

`confirmed`는 원본에서 해당 활동의 지시를 대조하고 학생용 요약을 작성한 행이다. `pending`은 검토 대기, `held`는 근거가 부족해 보류한 행이다. 두 상태 모두 공개 값은 `null`이다. 행의 `pdf_pages`는 파일 첫 장을 1로 센 물리 쪽이고 `printed_pages`는 교과서에 인쇄된 쪽이다. 검토 대기 행은 제목·준비물 확인 위치에서 시작한다. `wiki` 및 메모에 적힌 후보는 같은 판본의 학생 지면을 찾는 데 쓴다. 원본 PDF 파일별 식별값은 `source-files.json`에 보관한다.

## 이어서 작업하기

1. 해당 교재의 대기 행을 고른다. 기존 중학교 기록은 [행별 원자료 대조표](../../../docs/review/full-454/all-rows.json), 나머지는 [통합 자료](../../extraction/combined-20260922/science_experiment_supplies_combined.json)에서 교재와 쪽을 추적할 수 있다.
2. PDF 지면의 제목, 실제 학생 지시, 이어지는 쪽과 그림을 확인한다. 같은 쪽의 별도 활동·교사용 답안·보충 실험을 구분하고, 수치·단위·선택 조건·명시된 안전 지시를 확인한다. 원문에 없는 순서나 수량을 채우지 않는다.
3. 검토 파일에서 해당 행의 상태와 `note`를 기록한다. 확인한 행에만 `groups`를 넣는다. 각 묶음의 `heading`은 단일 과정이면 `null`, 하위 과제가 나뉘면 그 제목을 쓰고, `steps`에는 순서대로 학생이 수행할 동작을 적는다.
4. 프로젝트 루트에서 다음 명령으로 공개 파일을 생성하고 검증한다. 사용한 PDF를 가지고 있다면 `--source-dir`에 위키의 `raw` 경로를 지정해 파일 해시도 검사할 수 있다. 검증 결과에 확인·보류·대기 건수가 표시된다.

원자료의 쪽과 실제 학생 지시가 있는 쪽이 전혀 겹치지 않으면 PDF에서 다시 확인하고, 검토 행에 `reference_correction: true`와 교정 근거를 기록한다. 부록을 함께 확인했을 때도 인쇄 쪽과 PDF 물리 쪽을 각각 기록한다.

```sh
python scripts/build_procedures.py
python scripts/build_procedures.py --check
node scripts/verify_core.mjs
```

## 그림 없이 읽을 수 있는지 확인하기

단계별로 학생이 이미 가지고 있는 정보와 새로 읽어야 하는 정보를 구분한다. 학생이 방금 촬영한 사진이나 측정한 그래프라면 어느 단계에서 만든 것인지 밝힌다. 교재가 제공하는 정보라면 번호·색·기호가 가리키는 대상, 관찰 위치, 비교하는 데이터와 단위를 본문에 적는다. 원본에서 조건을 확인할 수 없고 그 조건이 수행에 반드시 필요하면 보류한다.

해안선을 맞추거나 회로·광원을 배치하는 등 위치 관계가 필요한 묶음에는 `figures`를 추가할 수 있다. 각 항목은 `file`, `caption`, `alt`를 가진다. 파일명은 `활동ID-original-두자리순번.svg`이며 실제 파일은 `site/dist/procedure-figures/`에 둔다. `caption`은 무엇을 보는지, `alt`는 학생이 비교하거나 조작할 때 필요한 관계를 설명한다. 범례와 단위가 읽히는지, 교사용 예시 답안이나 채점 표시가 섞였는지 확인한다. 별도 부록이나 다른 지면에서 보충했다면 내부 기록에 근거를 남긴다.

검색기는 학생용 과정과 해당 묶음의 시각 자료만 제공한다. 상세 열기·재시도·창 전환·약품과의 독립 로딩, 이미지 로딩 및 화면 너비별 표시 검사는 [브라우저 검증](../../../scripts/verify_optional_loading.cjs)에 포함되어 있다.

## 독립 작성과 공개 범위 (2026-11-05)

- PDF 지면 캡처·원본 이미지 추출·원작의 구도나 퍼즐 배열을 따라 그리는 방식은 공개용으로 사용하지 않는다.
- 과학적 사실, 확인된 수치·단위·조건과 학생이 해야 할 동작을 먼저 구분한 뒤 별도의 설명과 도식으로 구성한다. 순서를 바꾸면 안전이나 관찰 결과가 달라지는 단계는 유지한다.
- 실제 관측 사진 대신 만든 특징 요약·원리 모형은 자료의 성격을 본문과 그림에 명시한다. 교과서 관측값처럼 새로운 값을 꾸며 넣지 않는다. 새로 구성한 가상 사례·게임은 예시임을 밝히고 과학적 조건과 해답을 검증한다.
- 짧은 공통 수행 지시·과학용어·사실의 일치는 자체로 독창성이나 법적 적법성을 결정하지 않는다. 기계적인 동의어 치환이나 유사도 수치 맞추기를 하지 않는다.
- 공개 그림은 자체 SVG 도형과 텍스트로 작성한다. 래스터 이미지 삽입, 외부 자원 참조, 실행 가능한 요소는 생성기에서 거부한다. 독립 지리 데이터 등 외부 사실 자료를 이용하면 해당 이용 조건과 근거를 기록한다.
- 기존 추출본·검토표·캡처는 로컬 전용이다. `source-index.json`은 활동 ID별 원자료 식별과 최초 쪽 위치만 담아 공개 생성기가 원문 사본 없이 동작하도록 한다.
