## 근거와 해석

- `textbook_wiki/wiki/standards`는 중학교 범위였으므로 고등학교 코드는 `textbook_wiki/raw`의 해당 선생님 교과서 성취기준 표에서 확인했다. 31개 기준 목록은 `standards_inventory.json`에 문장·PDF 쪽·원문·원본 경로와 해시를 기록했다. 이 작업은 별도 국가 고시 원문과의 독립 대조를 주장하지 않는다.
- 직접 연결은 성취기준 표에서 해당 활동명을 명시한 경우이다(미래엔 24건·동아 6건). 내용 대조는 활동 수행과 기준의 관련성을 판단한 결과이다. 부분 요소·선수 학습·확장 연결도 포함하므로 기준 전체를 평가하는 활동이라는 의미는 아니다.
- 각 활동의 `source.standard_mapping`과 출판사별 매핑 JSON에 코드·연결 방식·판단 이유·활동 인용·기준 인용·쪽수를 보존했다. `[…]`는 떨어진 인용 사이 생략 표시이다. 글꼴 오류는 기록된 원본 이미지 대조로 확인했다.
- 기준이 여러 개일 때 `성취기준`은 줄바꿈한 대괄호 코드, `성취기준코드`는 배열, `성취기준내용`은 코드와 기준 문장 배열이다. 미확인은 각각 null·빈 배열·빈 배열이다.
- 지학사 통합과학1 전자배치 활동의 73쪽 연속 지면을 보완했다. 시작 쪽 72와 제목·준비물은 변함없다.
