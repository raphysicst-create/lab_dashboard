## 데이터 읽는 법

- 기존 원자료의 `단원명`, `성취기준`, `출판사`, `쪽`, `탐구활동`, `교구` 열을 유지하고 교과서·대표저자와 `source` 근거를 추가했다. `data`에 활동이, `metadata.source_books`에 권별 원본/해시가 있다.
- 탐구·해 보기 외에도 제목과 학생 수행이 분명한 창의융합·프로젝트·토론·일부 단원 열기·진로 활동을 포함한다. 일반 도입 질문·본문 확인 문제·평가·읽을거리·교사 예시·목차 중복은 제외한다. 출판사별 활동 유형은 `source.activity_type`에 보존했다.
- `교구`는 학생 본문에 명시된 준비물만 전사했다. 목록 미기재 177건은 `null`이며 실제로 준비물이 필요 없다는 뜻은 아니다. 절차·삽화·교사 예시에서 재료·규격·수량을 추정하지 않았다.
- 사용자 지정에 따라 모든 활동을 고1로 기록했다(`학교급: 고등학교`, `학년: 1`, `학년표시: 고1`). `textbook_wiki` 원본 교과서의 성취기준 31개를 확인하여 411건을 연결했다. 직접 연결 30건, 내용 대조 연결 381건이며 근거 부족 4건은 `null`이다. 내용 대조는 일부 요소·선수 학습·확장 활동 연결도 포함하며 출판사가 지정한 공식 활동별 배정이라는 뜻은 아니다.
- `성취기준`에는 대괄호 코드, `성취기준코드`에는 코드 배열, `성취기준내용`에는 기준 문장을 기록했다. `source.standard_mapping`에서 연결 방식·판단·활동 및 기준 인용문·출처 쪽을 확인할 수 있다.
- `쪽`은 인쇄 쪽이고 `source.pdf_pages`는 1부터 시작하는 PDF 쪽이다. 통합과학 1·2는 권수이며 두 권 모두 사용자 지정 고1이다.
- 목록의 줄바꿈은 원문 조판을 보존하므로 물품 사이가 아닌 단어 중간에도 있다. 줄바꿈만으로 개별 물품을 분리하면 안 된다.
- 천재교과서 통합과학1의 `(1)` 사본은 SHA-256가 동일하여 중복 추출하지 않았다.

## 확인 및 보존

10권 원본 해시·실제 PDF 쪽수, 필수 필드·null·ID 중복·원문 근거, 전 1,744쪽 coverage와 양방향 참조, 기록된 이미지 검토 범위, 독립 표본 23건 검증을 통과했다. 후속 검증에서 415개 활동의 고1 지정·매핑 적용과 31개 기준·근거 인용을 대조했다. 원본 모든 픽셀의 판독이나 내용 대조 연결의 공식 배정을 보증하는 검사는 아니다.

지학사 ‘과학관 탐방 프로젝트’와 동아 ‘개체군 변동 모의실험하기’·‘직업 탐구 활동’은 누락 역검색과 이미지 대조 후 포함했다. 교사 주석의 추가 시약·농도·수량은 학생 준비물에 섞지 않았다.

기존 원자료 JSON과 검토용 엑셀의 SHA-256는 작업 전과 같다. 중학교 통합본은 별도 사용자 요청 작업에서 커밋 `e10b6b9`로 변경되어 그 최신 해시를 보존 확인했다(`protected_original_updates.json`). 최초 baseline은 그대로 보존했다. 공개 사이트에 적용하지 않은 별도 추출 결과이며 실험 기자재/준비물 분류는 추가하지 않았다. 원본 PDF는 읽기만 했다.

재검증:

```powershell
python -X utf8 scripts/extraction/map_integrated_achievements.py --check
python -X utf8 scripts/extraction/verify_integrated_science.py
```

Python과 PyMuPDF가 필요하다. 자세한 실행 방법은 프로젝트의 `scripts/extraction/README.md` 참고.
