# 고1 준비물 분류

사용자 요청에 따라 기존 중학교 분류를 고1 활동에 적용한 내부 검토 기록입니다. 원본 고1 추출본은 변경하지 않고, 부록이 제외된 통합 JSON 414행에 적용했습니다.

- 원문 목록 238행, 목록 없는 176행(null 유지)
- 항목 954개: 기자재 724 / 준비물 230, 정규화 고유 품목 362종
- 기존 동일 품목 631개 출현의 분류 일치 확인
- 중학교 862행·기존 품목 카탈로그 변경 없음

세 manifest는 모든 활동 ID를 포함합니다. items의 raw/span은 교구 원문의 정확한 부분 문자열이며 줄바꿈·괄호·규격·농도·수량을 보존합니다. 원문의 안내 문장 1개는 non_items에 보존했습니다. catalogue.json은 고1 품목의 출현 역참조입니다.

동일 품목의 기존 결정을 우선하고, 새 품목은 사용자 그룹과 학생 본문의 실제 용도로 판단했습니다. 보류 검토 9개는 유사한 기존 품목과 활동 용도 기준으로 최종 분류했으며 해당 reason에 편집 판단과 추정하지 않은 내용을 적었습니다. 이를 새 사용자 직접 지정으로 기록하지 않았습니다. 대체 선택지와 묶음 재료는 분리하지 않아 원문의 선택 관계를 유지합니다.

적용: scripts/extraction/classify_integrated_supplies.py. 변경 전 사본과 해시 이력은 combined-20260922/decision_history/20260923-high-classification에 있습니다. 분류 근거와 원문 범위는 제품 화면에 노출하지 않습니다.
