## 읽는 방법

기존 자료의 `단원명`, `성취기준`, `출판사`, `쪽`, `탐구활동`, `교구`를 유지하고 출처를 추가했다. `source.pdf_pages`는 PDF 파일의 1부터 시작하는 페이지, `쪽`과 `source.printed_pages`는 교과서 인쇄 쪽이다. K7 본문은 PDF쪽=인쇄쪽+1, K8 본문은 PDF쪽=인쇄쪽이다. 엑셀 원자료가 아니므로 `source_row`는 null이다.

원본은 교과서 본문과 교사용 주석이 결합된 지도서 형식이다. 학생 본문의 제목 있는 수행 활동을 대상으로 탐구, 해 보기, 미래 역량, 창의 융합, 주제 통합 등을 포함했다. K7의 탐구 방법 익혀 보기 3단계는 제목별 기록하되 동일 연속 탐구라는 `series_id`를 두었다. 도입 질문·평가·정답·목차의 중복 지면과 교사용 대체 활동은 제외했다.

준비물은 명시된 목록만 옮겼다. 목록을 찾지 못한 40건은 null이며 ‘준비물 불필요’라는 뜻이 아니다. 절차·사진·교사용 예시로 빈칸을 채우지 않았다. 체크박스 줄바꿈과 한 줄 목록 등 원래 표현을 최대한 유지했고, PDF 글꼴 해독 오류는 이미지에서 확인한 글자로 옮겼다. K8 38쪽 목록의 ‘수조’ 반복처럼 원문 자체의 중복은 보존했다.

성취기준은 169건 모두 null이다. 대단원별 성취기준은 존재하지만 개별 활동과의 직접 연결이 확인되지 않아 임의 배정하지 않았다. 활동별 성취기준 매핑은 별도 검토가 필요하다.

교과서의 원래 단원명·로마 숫자를 보존하고 K7/K8 학년을 메타데이터로 기록했다. 기존 사이트의 사용자 지정 1~15단원 매핑에 강제로 맞추지 않았다. 통합본은 기존 454개 자료와 별도이며 웹사이트 공개 데이터로 자동 반영되지 않는다.

## 검증과 수정

- 전체 646쪽을 텍스트·좌표로 조사했고 페이지별 판정과 레코드 연결을 기록했다.
- 추출 에이전트가 K7 65쪽, K8 90쪽의 페이지 또는 활동 영역 이미지를 직접 확인했다. K8 활동 제목 87개는 제목 영역 이미지로 다시 대조했다.
- 주 에이전트는 원본 30쪽을 별도로 이미지 검토했다. 두 검토 범위에는 중복이 있으므로 수를 더해 고유 검토 페이지 수로 해석하지 않는다.
- 원문 이미지에서 작성한 별도 기준으로 제목·준비물·연속 지면 17건을 대조했다. 구조, 필수 열, ID, 쪽 범위, 원본 해시, 뷰, 전체 페이지별 coverage 연결 검사와 함께 통과했다.
- 검토 중 K7 익혀 보기 활동 누락, ‘드라이어’ 오독, K8 ‘칸딘스키’·‘끌어당기기’ 제목 오독, 광합성 준비물 3개 누락 및 연속 지면 누락을 찾아 수정했다.
- 원래 `science_experiment_supplies.json`의 SHA-256은 작업 전후 `22748932ad38860145bdd1c47eb6cd437bfc965e90cbdbff303477133e9336ff`로 동일하다.

전체 646쪽의 모든 픽셀을 전수 시각 판독한 결과는 아니다. 활동의 포함 기준과 남은 판독·연결 한계는 권별 보고서 및 coverage에 명시했다. 기계 검증 통과는 교과 내용 또는 성취기준 연결의 전수 확정을 뜻하지 않는다.
