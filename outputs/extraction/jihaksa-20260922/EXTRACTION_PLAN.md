## 추출 범위

1. 목차와 본문 전체 페이지의 텍스트를 조사하여 제목이 있는 독립 수행 활동을 목록화한다. 탐구·해 보기·단원 말 프로젝트/미래 역량 활동을 포함한다. 실험에 한정하지 않고 조사·토의·만들기도 포함한다.
2. 도입 질문, 단순 확인·평가 문항, 정답·해설, 앞부속 사용 안내에 복제된 본문, 교사용 대체 활동은 활동 데이터에서 제외하고 범위 판단을 기록한다.
3. 같은 활동이 여러 쪽에 걸치면 하나로 묶고 근거 페이지를 함께 기록한다. 실제 다른 제목·활동은 같은 쪽에 있어도 나눈다.
4. 학생 본문에 명시된 준비물 목록만 옮긴다. 절차·삽화·교사용 팁으로 준비물을 보충하지 않는다. 규격·농도·온도를 필요 수량으로 바꾸지 않는다. 명시 목록이 없으면 `교구: null`이다.
5. 줄바꿈을 잇는 표기 정리는 가능하되 원래 단어·괄호·기호·숫자를 유지한다. 추출 오류는 이미지로 확인하고 교정 근거를 남긴다. 판독할 수 없는 값은 추정하지 않는다.
6. 성취기준은 직접 명시되고 해당 활동과의 연결이 확인된 경우만 기록한다. 학습목표를 성취기준으로 바꾸거나 기존 다른 출판사 자료를 복제하지 않는다.

## 쪽·단원·학년

- `쪽`은 교과서에 보이는 인쇄 쪽이다. `source.pdf_pages`는 파일 내 1부터 시작하는 PDF 페이지다. 둘을 분리해 기록한다.
- 단원 번호와 단원명은 교과서 원문을 보존한다. 파일 구분에 따라 K7은 grade 1, K8은 grade 2로 기록한다.
- 기존 웹사이트의 사용자 지정 매핑(1~8단원=1학년, 9~15단원=2학년)을 교과서 자체 번호에 강제로 적용하지 않는다. 통합·게시를 위한 매핑은 이번 추출과 별도다.

## 결과 형식
