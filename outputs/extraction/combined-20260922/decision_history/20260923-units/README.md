# 단원명 통일

기존의 아라비아 숫자·로마 숫자·번호 없는 표기와 대단원/소단원 혼합으로 같은 단원이 분리되는 문제를 수정했다.

- 중학교: 기존 교육과정 통합 번호 1~23을 사용한다. 이는 개별 교과서 안의 순번과 다를 수 있다.
- 고1: 통합과학 1·2 각각 1~3단원이다. 권수는 학년이 아니다.
- 부록 1개는 별도이며 단원 번호는 null이다.
- 실제 원문 대단원 이름과 학교급·권수로 연결한다. 성취기준을 이용해 활동을 다른 단원으로 옮기지 않는다.
- 원래 단원명 전체(로마 숫자와 소단원 포함)는 `단원명 원문`과 공개 `unit_raw`에 보존한다.

예: `물질의 특성`, `Ⅰ. 물질의 특성`, `8. 물질의 특성`은 통합 표시 `8. 물질의 특성`으로 합친다. 사용자 지정 중1 활동과 교과서 기준 중2 활동의 학년은 그대로 유지한다.

`unit_catalog.json`은 30개 단원(중학교 23·고1 6·부록 1), `mapping.json`은 1,277개 활동별 이전·이후 값이다. 수정된 단원명은 823개이며 모든 다른 활동 필드는 보존했다. 적용 전 통합 JSON과 공개 활동 JSON을 이 폴더에 보존했다.

검증 결과는 `output/validation/unit-normalization-20260923/`에 있다.
