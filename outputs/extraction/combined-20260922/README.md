# 원자료·지학사·YBM 통합 자료

원자료 454건, 지학사 169건, YBM 239건을 합친 862개 활동이다. [통합 JSON](science_experiment_supplies_combined.json)에 준비물 분류를 추가했다.

| 필드 | 내용 |
|---|---|
| `교구` | 원문 그대로. 수정하지 않음 |
| `실험 기자재` | 실험 후에도 남아 반복 사용하는 것으로 분류한 항목 |
| `실험 준비물` | 투입·소모하는 시약·물·식재료·접착 재료 등 |
| `분류 보류` | 사용·회수 방식이나 구성 물품이 불분명해 사용자 판단이 필요한 항목 |
| `준비물 분류` | 항목별 ID·원문·원문 내 위치·분류·판단 근거 |

사용자가 예로 든 비커, 시험관, 스마트 기기, 눈금실린더, 핀셋, 전자저울, 장갑, 보안경, 실험복, 유리병, 약숟가락은 기자재로 처리했다. 장갑은 재질과 관계없이 사용자 지정 분류를 우선했다. 약품규정 목록에 이름이 없는 시약도 명확한 투입 재료이면 실험 준비물로 분류했다. 농도·규격·수량을 추정하거나 삭제하지 않았다.

## 현재 결과와 검증

준비물 목록이 명시된 759개 활동에서 총 4,019개 항목 출현을 처리했다. 기자재 2,924개, 준비물 1,095개, 보류 0개이다. 같은 항목의 반복 출현을 공백·유니코드 호환 표기 차이만 정리해 묶으면 각각 588·485·0개 표기이다. 물품 수량을 합산한 숫자는 아니다.

목록이 없는 103개 활동은 기존 `교구:null`과 새 분류 필드의 null을 유지했다. 알려진 목록에 특정 분류가 없을 때만 빈 배열을 썼다. 줄바꿈으로 끊긴 품목명, 괄호 안 쉼표, 여러 대상의 붙임딱지 표현을 품목 경계와 구분했으며, 원문 내 문자 위치로 역추적할 수 있다.

원자료 3개 파일의 해시, 862개 기존 행의 모든 필드, 분류 전후 뷰, 항목 경계의 누락·중복을 검사했다. [현재 검증 결과](classification_validation.json)를 참고한다. 이는 물품 분류의 전면 사용자 승인이나 교과서 원문 재검토를 의미하지 않는다.

분류 전 통합본은 [백업 JSON](science_experiment_supplies_combined.unclassified.json)에 보존했다. 기존 원자료, 지학사·YBM 추출본, 웹사이트 데이터는 변경하지 않았다. 재실행 방법은 `scripts/extraction/README.md`에 있다.
