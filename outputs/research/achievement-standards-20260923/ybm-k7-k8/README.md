## 근거와 판정

두 PDF의 각 단원 앞 `교육과정` 면에는 `[9과01-01]`부터 `[9과15-04]`까지 해당 학년의 코드와 문장이 있으며, 다음 `단원 지도 계획` 표에는 기준별 차시·교과서 쪽수·활동명이 있다. 2022 개정 교육과정의 중학교 과학 코드 체계이고, 교육부 고시 제2022-33호 [별책9] 과학과 교육과정의 공식 코드 58개와 일치한다. 교과서 문장은 PDF 추출 원문으로 별도 보존했으며, 공식 문장과의 표기 차이는 아래에 명시했다. PDF의 제작일은 발행·판쇄 연도로 해석하지 않았다.

`direct`는 **학생 활동 지면에 코드가 인쇄되었다는 뜻이 아니라**, 교사용 `단원 지도 계획`의 성취기준 셀과 같은 행에 활동명이 직접 기재된 경우다. 표의 제목과 학생 지면 제목 사이 조사·조사의 차이(예: K7 44번 `놀이기구에서의`/`놀이기구에서`, K7 54번 `기체의 온도와 부피의 관계`/`기체의 온도와 부피 관계`)는 차시와 인쇄쪽, 활동 내용을 함께 확인했다. 이 두 건도 해당 코드 셀 안에 있어 `direct`다. 현재 `scope_based`만으로 연결한 활동은 없다.

성취기준 셀의 경계를 PDF 표의 가로선 좌표와 활동의 교과서 쪽수 위치로 전수 대조했다. 별도 `실천하는 생태 시민` 행 15건은 지도계획에 활동명이 있어도 **성취기준 열이 공란**이다. 따라서 공식 기준을 확정하지 않고 `standard_codes: null`로 두었다. 내용이 기준 문장과 명확히 닿는 9건만 `candidate_codes`에 후보를 기록했다. 나머지 6건은 `unconfirmed`다. 같은 대단원에 실렸다는 이유만으로 앞 행의 코드를 이어받지 않았다.

## 교과서 문장과 고시 문장

58개 코드는 공식 목록과 모두 일치한다. 교과서와 고시의 문장 표기가 다른 8개는 교과서 원문을 JSON `raw_text`로 보존했다. 다수는 띄어쓰기·가운뎃점 모양 차이이다. 특히 K8 PDF 143쪽 `[9과11-04]`는 교과서에 **“물질을 이루는 입자인 원자, 분자, 이온 등으로…”**라고 인쇄되어 있고, 고시 원문은 **“물질을 이루는 입자는 원자, 분자, 이온 등으로…”**이다. 원문 PDF 확대 이미지로 교과서 표현을 확인했다. 이를 고시 문장으로 조용히 바꾸지 않았다. 나머지 표기 차이는 K7 `9과02-04`, `9과02-05`; K8 `9과09-01`, `9과12-01`, `9과12-03`, `9과13-01`, `9과13-03`이다.

출처 PDF: `textbook_YBM_K7.pdf` 252쪽, `textbook_YBM_K8.pdf` 328쪽. 각 기준과 활동에는 PDF쪽, 교과서 인쇄쪽 또는 지도계획 A쪽, 인용문을 JSON에 기록했다. 단원 계획의 코드 셀·활동 행 경계는 K7 PDF 14·148·184쪽, K8 PDF 256쪽 등을 렌더 이미지로 재확인했다. 학생 지면의 활동 제목과 지도계획의 인쇄쪽을 151건 전수 대조했다.
