# 디자인 목업 4종

`index.html`에서 Cal.com, IBM Carbon, Airtable, Starbucks 스타일 목업을 비교할 수 있습니다.

- HTTP로 실행하면 `../dist/data/activities.json`의 454개 SSOT 활동 데이터를 사용합니다.
- HTML 파일을 직접 열어 데이터 요청이 차단되는 환경에서는 8개 예시 데이터로 자동 대체합니다.
- 검색, 학년·단원·성취기준·출판사 필터, 정렬, 초기화, 학급 설정, 상세보기 모달이 동작합니다.
- 740px 이하에서는 필터가 접이식 모바일 패널로 바뀝니다.
- 외부 폰트나 이미지가 없어 파일을 직접 열어도 동작합니다.
