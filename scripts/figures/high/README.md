# 고등학교 탐구용 독립 도식

`render.py`는 직접 작성한 사실 명세와 SVG 도형으로 78개 자료를 다시 생성한다.

```powershell
python -B -X utf8 scripts/figures/high/render.py
```

입력은 `outputs/review/procedures/high.json`의 활동 식별자와 그림 순서이다. PDF, 교과서 이미지, 캡처, 외부 URL, 삽입 사진, 기존 도안 좌표를 읽지 않는다. 표의 정보 배치, 색, 도형, 종이 모형의 조립 방식 및 활동용 암호·낱말판은 새로 작성했다. `S`의 수치와 조건은 해당 활동 검토 기록에 연결된 원자료에서 확인한 사실이다. 출처와 확인 쪽수는 공개 화면이 아닌 검토 JSON에 보존한다.

## 자료 형식과 해석 범위

- 사진이 필요했던 관찰 자료는 확인된 특징의 개념 모형 또는 비교표로 바꾸었다. 실제 사진·현미경 영상·실측 곡선이라고 표시하지 않는다.
- 기후 및 관측 그래프를 요약한 표에서 눈금으로 읽은 수치는 근삿값임을 표시한다. 표로 바뀐 활동은 주어진 값과 추세를 비교하도록 질문도 변경했다.
- 스펙트럼은 선의 대응을 확인하는 정성 모형이다. 실제 파장 축이나 선 세기 자료로 사용할 수 없다. 수소의 장파장선은 빨간 구간, 나트륨 이중선은 노란 구간에 놓았다.
- DNA 모형은 테이프로 연결하는 새로운 당·인산·염기 부품이다. 원래의 특수 절개선과 끼움 구조를 복제하지 않았다. 염기쌍과 두 골격의 반대 방향은 유지한다.
- 단백질, 부리, 전동기, 세포막 등은 구조 또는 관계를 설명하는 모형이며 원자 좌표나 해부 측정 자료가 아니다.
- 기존 미확인 활동 2건은 확인 상태를 바꾸지 않았다.

## 새 활동 설계의 확인 사항

- `jihaksa_is1_0035`: 기준 서열 `AUGGCUACGUUCGAUCCA`와 한 문자 치환, 네 번째 문자를 삭제한 서열을 비교한다. 삭제 결과를 세 문자씩 읽으면 `AUG CUA CGU UCG AUC CA`이다. 마지막 두 문자는 연결하지 않으며, 대응표는 실제 유전 암호표가 아닌 활동용 표임을 표시한다.
- `visang_IS1_047`: 숫자 1~4의 세 자리 부호를 서로 다른 기본 자모 24개에 일대일 대응시켰다. 새 메시지는 “과학은 질문에서 시작”이며 복합 모음은 기본 자모를 합쳐 읽는다.
- `visang_IS2_014`: 새 9×9 판에 연소, 광합성, 세포호흡, 기화, 응고, 융해를 배치했다. 가로·세로·대각선 탐색으로 각 용어가 존재하는지 확인한다.
- `miraen_IS1_042`, `visang_IS1_050`: 새 DNA/RNA 서열은 주형 가닥과 RNA 사이의 상보 관계를 만족한다. 색과 도형은 정보 전달을 위한 활동용 기호이며 실제 아미노산 형태를 뜻하지 않는다.
- `visang_IS1_027`: 재료를 구분하는 새 10칸 판을 사용한다. 2개 주사위의 합과 같은 눈일 때의 추가 차례 조건을 유지하고, 10번 이상에 도달하면 끝내도록 도착 조건을 명시했다.
- `jihaksa_is2_0001`: 원자료의 유인원 200만 년 전 표현을 유인원 계통의 화석 연대 약 2520만 년 전으로 교정했다. 화석 연대는 최초 출현을 확정한 시점과 다르다. 근거는 [Stevens et al., Nature (2013)](https://www.nature.com/articles/nature12161)이다.
- `miraen_IS2_019`: 원자료를 재대조하여 1905년 늑대 수를 기존 오기인 약 40마리에서 약 400마리로 바로잡았다. 사슴은 약 3,800마리이다.

법적 판단을 대신하는 보증 문서가 아니라, 독립 작성 방법과 과학적 해석 범위를 기록한 구현 문서다.
