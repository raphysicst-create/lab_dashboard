# 중학교 독립 시각 자료

`build.py`는 표준 Python 라이브러리만으로 34개 활동의 SVG 35개를 `site/dist/procedure-figures/`에 만든다. 실행 위치는 저장소 루트다.

```sh
python scripts/figures/middle/build.py
```

생성 과정은 교과서 PDF, 기존 WebP, 추출 이미지, 이미지 생성 모델을 읽지 않는다. 텍스트와 기본 도형, 공개 지리 좌표만으로 작성한 독립 레이아웃이다. SVG 안에 외부 참조·스크립트·래스터 그림을 넣지 않는다. 대응 파일명은 `manifest.json`에 기록한다.

## 입력과 사실 확인

- `activity-ids.json`: 기존 활동과 연결할 ID 목록. 교과서 문구는 포함하지 않는다.
- `natural-earth-countries.json`: Natural Earth의 국가 경계 좌표. 속성은 지역 선택에 필요한 `CONTINENT`, `NAME_EN`만 남겼다. Natural Earth는 모든 벡터·래스터 데이터를 퍼블릭 도메인으로 제공한다고 밝힌다. [공식 이용 조건](https://www.naturalearthdata.com/about/terms-of-use/).
- `build.py`의 수치·단위·관찰 특징은 각 활동의 읽기 전용 원자료에서 확인했다. 확인한 PDF 파일명과 물리 쪽은 `review.json`의 `sources`에 있다. 재현을 위해 그 PDF가 필요하지는 않다.
- 암석·검정말·자기장·시차 그림은 사진이 아닌 특징 또는 위치의 모형이다. 복사 평형·습도·염분·해류·기압 배치는 정성 관계 자료이며 관측 곡선이나 지도를 모사하지 않았다. 시간·온도·거리 등의 가짜 측정값을 추가하지 않는다.
- 태양과 별의 실제 관측 자료가 필요한 활동에는 조사·기록 안내를 제공하고, 실제 자료를 학습자가 공식 관측 서비스 또는 천문 자료에서 확인하도록 했다.

## 독립적으로 재설계한 활동

- 대륙 비교는 자연 해안선의 대응만 이용한다. 기존 퍼즐의 색띠나 화석 그림을 재현하지 않는다. 별도 조각 그림은 축척이 서로 다르며 정확한 판게아 조립 도안으로 사용하지 않는다고 명시했다. 남극은 남극점 중심 좌표로 표현한다.
- 원소 놀이판은 원자번호 1~20의 기호를 새 4×5 배열로 구성하고 출발선을 아래에 둔다. 원소 기호 암호는 학습자가 독립 단서를 만드는 활동으로 바꿨다.
- ABO 가계도는 새 교육용 가상 가족이다. 아버지 AO와 어머니 BO 사이에서 A/B/AB/O 자녀가 가능하다. B형 딸 BO와 AB형 배우자의 자녀가 AB형일 확률은 1/4이며 대립유전자 조합으로 검증했다.
- 귀지 유전 사례도 새로운 가상 가족 관계로 구성했다. 두 우성 표현형 부모에게 열성 표현형 자녀가 가능한 조건을 사용한다.
- 원교재 바람 플렉사곤의 접기·접착 배열은 사용하지 않는다. 새로운 도안의 실제 작동을 검증하지 못해 `ybm_k9_0025`는 공개 과정을 보류했다.

`review.json`은 408개 활동 검토 범위, 재작성 통계, 수치 표기 변화 6건의 검토 결과를 보존한다. 이 기록은 법률상 권리 상태에 대한 보증을 뜻하지 않는다.
