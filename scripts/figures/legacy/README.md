# 기존 중학교 활동의 독립 도식

이 폴더는 기존 중학교 활동 30개의 SVG 34개를 재생성하는 코드와 최소한의 공개 좌표 자료를 담는다. 교과서 PDF, 캡처, 이미지 추출 파일 또는 원문 추출 자료를 입력으로 사용하지 않는다. 과학적 조건과 수치는 확인된 사실을 유지하되 설명, 도형, 배열, 게임판은 별도로 구성했다. 이는 제작 근거 기록이며 법적 적합성을 보증하는 문서는 아니다.

프로젝트 루트에서 다음 명령을 실행한다. Python 표준 라이브러리만 사용하며 네트워크 연결이 필요 없다.

```sh
python -B scripts/figures/legacy/build.py
```

`basic.py`가 기구·모형·비교표 23개를, `build.py`가 지리 자료와 나머지 학습 모형 11개를 작성한다. 출력은 `site/dist/procedure-figures/activity_*-original-*.svg`이고 설명 색인은 이 폴더의 `manifest.json`이다. SVG에는 텍스트와 벡터 도형만 있으며 스크립트, 외부 리소스, 포함된 래스터 이미지가 없다. 2026-11-05 패키지 실행으로 34개 전체 생성을 확인했다.

## 좌표 자료의 출처와 범위

상세 URL, 이용 근거, 수집일, 파일 SHA-256은 `sources.json`에 기록했다.

| 자료 | 포함하는 데이터 | 이용 근거 |
| --- | --- | --- |
| Natural Earth 1:110m | 국가별 지리 좌표와 대륙·영문명 필드 177개 | [공식 이용 조건](https://www.naturalearthdata.com/about/terms-of-use/)의 퍼블릭 도메인 지리 데이터 |
| USGS 주요 판 경계 | 경위도 선 좌표, 경계명·분류·객체 ID 1,175개 | [USGS 저작권 안내](https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits)의 USGS 제작 데이터 |
| Smithsonian GVP | 홀로세 화산 1,214개의 경위도와 화산 번호 | [GVP 이용 조건](https://volcano.si.edu/gvp_termsofuse.cfm)에 명시된 정부 업무상 데이터베이스; 출처 표시 |

USGS의 응답 한도는 1,000개이므로 두 페이지를 수집했다. 서비스의 전체 개수 1,175와 수집 개수 및 고유 OBJECTID 개수가 같음을 확인했다. GVP 자료는 좌표와 번호만 보존했다. 화산 사진, 사진 링크·설명·촬영자 정보, 지질 설명문은 포함하지 않는다. 지도는 원본 지도 이미지를 가공한 것이 아니라 좌표로 새로 계산한 도형이다. 화산 지도는 최근 약 12,000년의 분화 이력이 있는 위치이며 현재 분화 중인 화산만을 뜻하지 않는다.

## 학습 모형의 설계와 한계

- **대륙 비교 조각 0018·0082·0208:** 5개 조각 모두 같은 반지름 190의 정사영을 사용한다. 조각별 바운딩 박스에 맞춰 크기를 조절하지 않는다. 투영 중심은 각 대륙에 따로 두었으므로 구면을 평면으로 옮길 때의 왜곡이 있으며 현대 해안선이 과거 대륙 경계와 정확히 맞는다는 뜻은 아니다. G·M·빙 기호는 대륙별 화석 또는 빙하 흔적의 존재를 뜻한다. 코드의 기호 배치 좌표는 도식 안에서 읽기 좋게 정한 위치이며 실제 산출지의 좌표·면적을 나타내지 않는다. 화살표는 확인한 이동 방향을 요약한 개념 표시다.
- **관측 안내 0062·0122·0184:** 실제 관측 사진과 구별되는 비교 기준·특징 표 또는 모형이다. 온도 측정값을 새로 만들지 않았다. 은하수 활동은 학습자가 수집한 여름·겨울 관측 사진을 기준에 따라 비교한다.
- **곡선 0133·0194·0220:** 온도 변화나 주기 같은 관계를 나타내는 도식이다. 용해도는 정량 눈금 없이 경향만 비교하며, 제시된 실험의 물·용질 양은 본문에서 유지한다. 소리 도식은 실제 악기 측정 신호가 아니라 이상적인 주기 파형이다.
- **지구계 놀이 0011:** 번호판, 영역 예시, 질문 카드 절차를 새로 구성했다. 도착 초과, 영역 예시 칸의 다른 말, 오답 카드의 처리와 도착 순위 점수를 명시했다. 원래의 사진이나 장식 경로를 사용하지 않는다.
- **소화 카드 0047:** 기관을 지나는 순서에 따른 빈 표와 글자 카드를 새로 설계했다. 각 빈 칸에 상태를 채우고 확인한 뒤 점수를 얻는다. 오답 카드는 되가져가며 반복해서 필요한 종류는 추가로 준비한다. 지방의 최종 소화 산물 표기는 확인한 과학 내용에 따른다.
- **생물다양성 놀이 0359:** 새 번호 경로, 네 사건 규칙, 생물 이름 카드를 사용한다. 시작 카드의 종류가 카드 목록에 모두 포함되는지 확인했다. 사건 카드는 재사용하고, 가져오거나 반납할 카드가 없으면 해당 증감을 생략한다. 비교 대상은 카드 장수가 아니라 서로 다른 생물의 종류 수다. 카드 증감은 실제 생태계의 변화량을 예측하는 자료가 아니다.
- **천문 위치 모형 0381·0382·0416:** 태양과 관측자·별자리 사이의 방향을 독립 배치했다. 0381은 위치 변화의 개념 표시이며 실제 별 배열, 고도·방위각, 관측 사진이 아니다. 황도 별자리 이름 카드는 등간격 모형으로 실제 별자리의 폭을 나타내지 않는다. 3월 관측점에서 태양 방향은 물고기자리 쪽, 반대는 처녀자리 쪽이며 6월에는 각각 쌍둥이자리·궁수자리 쪽이라는 관계를 대조했다.
- **시차 0060·0256:** 관측점과 표식의 상대 위치를 새 좌표로 구성했다. 0256에서 같은 번호의 관측점·표식을 잇는 두 선의 교점은 A가 B보다 관측자 가까이에 놓이도록 계산했다.
- **그 밖의 기구 도식:** 직접 설정한 도형과 화살표로 조립·관측 위치를 설명한다. 현상을 이미 관측한 사진이나 실측 도면처럼 표시하지 않는다.

## 2026-11-05 문구 검토 기록

`outputs/review/procedures/legacy.json`의 454개 활동을 검토했다. 원문과 같거나 가까운 문장, 원자료 특유의 이야기와 배열, 그림 교체에 따라 달라진 지시문을 중심으로 85개 활동의 본문을 다시 작성했다. 짧은 공통 기능 지시와 과학 용어를 바꾸기 위한 변경률 목표는 두지 않았다.

- 기존 단계 1,333개에서 1,296개로 정리했다. 변경 활동 안에서 기존 248개 단계를 211개의 새 문장 단계로 구성했다.
- 확인 상태 450개와 보류 4개를 유지했고 새로 보류한 활동은 없다.
- 활동별 숫자 토큰 집합의 손실은 없고 숫자-단위 쌍의 변경도 없다. 추가된 숫자는 영점 조절을 풀어 쓴 `0`과 원래 위치 모형에 표시된 8월의 날짜 `1·16·31`뿐이다.
- 이 기계적 비교는 누락 검출을 보조한다. 숫자 보존만으로 의미나 안전 지시가 같다는 결론을 내리지 않으며, 실험 조건·방향·자료 유형·안전 지시를 문장과 함께 대조했다.
- 30개 활동의 그림 34개를 모두 이 폴더의 독립 도식으로 교체했다. 기존 4개 보류의 자료 부재를 새 관측 결과로 메우지 않았다.

이 문서의 개수는 legacy 자료에만 해당한다. 다른 중학교·고등학교 자료, 웹 전체 검증과 배포 확인은 프로젝트의 별도 검증 기록을 따른다.
