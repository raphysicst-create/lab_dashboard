# 약품 선택 로딩 성능 비교

측정일: 2026-09-23. **첫 활동 화면은 빨라졌지만, 약품을 처음 열 때는 추가 대기가 발생합니다.** 공개 배포 전 변경 전후 코드를 같은 컴퓨터에서 비교한 결과입니다.

## 첫 활동 화면 준비 시간

각 환경에서 변경 전·후 각각 10회, 총 60회 측정했습니다. 표는 중앙값이며 괄호는 최솟값–최댓값입니다. 각 쌍의 측정 순서는 번갈아 바꿨습니다. 30개 비교 쌍 모두 개선판의 첫 활동 화면 준비가 빨랐습니다.

| 조건 | 변경 전 | 개선 후 | 중앙값 차이 | 감소율 |
|---|---:|---:|---:|---:|
| 로컬·속도 제한 없음 | 104.3 ms (103.1–107.8) | 97.4 ms (94.6–101.3) | 6.9 ms | 6.6% |
| 10 Mbps·지연 40 ms | 516.1 ms (500.3–538.2) | 442.2 ms (429.6–457.6) | 73.9 ms | 14.3% |
| 1.6 Mbps·지연 100 ms·CPU 4배 제한 | 1892.2 ms (1858.3–1942.2) | 1619.7 ms (1568.8–1636.0) | 272.6 ms | 14.4% |

빠른 로컬 환경에서는 차이가 약 7 ms로 작습니다. 제한된 두 회선 조건에서는 각각 약 74 ms·273 ms 줄었습니다. 실제 사용자가 똑같은 시간을 경험한다는 뜻은 아닙니다.

## 초기 요청과 다운로드

압축된 응답 본문만 합산했습니다. HTTP/TLS 헤더 비용은 포함하지 않았습니다. 모든 측정에서 같은 바이트 수가 나왔습니다.

| 항목 | 변경 전 | 개선 후 |
|---|---:|---:|
| 초기 전체 요청 | 11개 | 6개 |
| 초기 JSON 요청 | 4개 | 2개 |
| 초기 gzip 본문 | 178,953 B (174.8 KiB) | 154,337 B (150.7 KiB) |
| 압축 해제 후 초기 본문 | 1,774,228 B | 1,442,189 B |
| 약품을 한 번 연 뒤 누적 gzip 본문 | 178,953 B | 173,867 B |

처음 내려받는 압축 본문은 **24,616 B(24.0 KiB), 13.8% 감소**했습니다. 약품을 한 번 열면 누적 전송 감소는 **5,086 B(5.0 KiB), 2.8%**입니다. 나머지는 삭제한 데이터가 아니라 필요할 때로 미룬 데이터와 코드입니다.

이전 버전은 약품 화면·그림 모듈과 서로 다른 주소의 core.js까지 초기 로딩했습니다. 개선판은 이 요청들을 첫 화면에서 제외합니다. 초기 바이트 감소 비율과 시간 감소 비율은 같은 의미가 아닙니다.

## 약품 첫 진입과 두 번째 진입

초기 로딩이 끝난 후 약품 관리 버튼을 누른 순간부터 약품 목록의 표시 준비까지를 측정했습니다. 초기 로딩 대기시간은 이 표에 포함되지 않습니다.

| 조건 | 첫 진입: 전 → 후 | 두 번째 진입: 전 → 후 |
|---|---:|---:|
| 로컬·속도 제한 없음 | 31.9 → 49.9 ms | 32.2 → 33.2 ms |
| 10 Mbps·지연 40 ms | 31.8 → 121.1 ms | 32.9 → 33.5 ms |
| 1.6 Mbps·지연 100 ms·CPU 4배 제한 | 52.9 → 295.3 ms | 29.9 → 30.6 ms |

10 Mbps 조건에서는 약품 첫 진입에 약 89 ms, 제한된 1.6 Mbps 조건에서는 약 242 ms가 추가됐습니다. 두 번째 진입은 성공한 자료를 재사용하여 전후 차이가 약 1 ms 이내였습니다. 검색만 쓰는 사용자에게 첫 화면의 이득이 있으며, 약품을 바로 여는 경우에는 앞에서 줄인 대기가 일부 뒤로 이동합니다.

## 측정 방법과 범위

- 비교 코드: `ce243d373c507c59f5e53c26f8b18f5c21feedeb` → `1f7c0710b9ce6357a7939aa0e53af5709f831f0b`.
- 활동 1,276개를 포함한 공개 JSON은 두 버전에서 바이트 단위로 같습니다. Git 스냅샷을 읽기만 하고 앱 파일은 수정하지 않았습니다.
- Edge 153.0.4234.48, headless, 1440×1000 화면. 브라우저 준비용 2회는 결과에서 제외했습니다.
- 모든 회차는 새 브라우저 컨텍스트와 빈 캐시이며, 같은 HTTP/1.1 로컬 서버에서 미리 gzip level 6으로 압축한 파일을 제공합니다.
- 네트워크·CPU 제한은 브라우저의 개발자 도구 기능으로 적용했습니다. 1.6 Mbps 조건도 PC 화면 크기를 유지한 제한 실험이며 실제 휴대전화 측정이 아닙니다.
- 첫 화면 준비는 활동 수·카드·로딩 종료를 확인한 뒤 두 번의 requestAnimationFrame을 기다린 값입니다. 실제 모니터의 물리적 페인트나 LCP 점수는 아닙니다.
- 전송량은 초기 요청이 모두 끝난 후 수집하여 늦게 완료된 요청을 빠뜨리지 않았습니다. 약품을 연 뒤의 누적량도 별도로 수집했습니다.
- 공개 사이트의 CDN·HTTP/2·캐시·실사용자 회선에 따라 결과는 달라질 수 있습니다. 공개 서비스의 실사용 성능 측정이나 배포 완료를 의미하지 않습니다.
- 개선판 초기 압축 본문의 약 86%는 activities.json입니다. 이번 변경만으로 초기 데이터 비용 전체가 크게 없어지는 것은 아닙니다.
