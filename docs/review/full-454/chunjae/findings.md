# 천재교과서 188행 전수 검토 결과

## 결론

- 담당 범위는 천재(정대홍) 96행과 천재(임성숙) 92행, 합계 188행이다.
- 정대홍 판본 96행: 일치 82행, 표현차이 2행, 수정후보 12행이다.
- 임성숙 판본 92행: 추가 제공된 저자 판본 K7·K8 PDF와 직접 대조해 일치 66행, 표현차이 8행, 수정후보 14행, 근거부족 4행이다. 정대홍 판본의 같은 제목·쪽수·준비물을 대신 적용하지 않았다.
- 기존 검토표 A:H는 188행 모두 JSON과 일치했고, 기존 I:W는 ‘교과서 대조 미확인’ 상태였다. JSON↔XLSX 일치는 변환 정확성일 뿐 사실 증거로 쓰지 않았다.
- 담당 ID 누락 0, 중복 0이다.

## 준비물 역방향 점검

- 정대홍 96행에서 PDF 학생용 본문의 `준비물` 체크항목을 원문 목록과 양방향으로 비교했다.
- 준비물 일치 84행, 표현차이 2행, 누락/null 수정후보 10행이다.
- `activity_0044`, `activity_0046`은 텍스트 추출에서 `℃`가 깨져 인쇄면 이미지를 확인했고 원문의 `80~90 °C의 물`과 일치함을 확인했다.
- 교사용 보충 준비, 대안 실험, 안전 유의사항의 보호구를 학생용 기본 준비물에 합치지 않았다.

## 자료부족 범위와 제한

- 임성숙 `activity_0386`·`0393`·`0094`는 학생용 준비물의 명시적 목록이 없어 교구 목록의 완전성을 확정하지 않았다. `activity_0067`은 제공된 임성숙 K8 PDF에 원문 활동명이 수록되지 않아 쪽·활동명·교구를 근거부족으로 두었다. 다른 활동의 준비물을 이 행에 대입하지 않았다.
- 임성숙 `activity_0100`·`0101`은 원문 성취기준 문구 자체는 공식 문구와 일치한다. 다른 기준과의 연결 검토는 내용상 추론이며 확정 오류가 아니다.
- 사용자 지정 학년 매핑(1~8단원=1학년, 9~15단원=2학년)은 확정 설정으로 존중했고 오류 후보로 다루지 않았다.
- 수량·농도·안전·규격을 추정하지 않았고, 자료에 없는 준비물을 일반 지식으로 보충하지 않았다.
