# 과학 탐구활동 454행 교과서 대조 보고

## 결론

- 원본 454행 전부를 6개 원문 필드(단원명·성취기준·출판사·쪽·탐구활동·교구)별로 기록했다. 고유 ID 454개이며 원본 대비 누락·추가·중복은 0개다.
- 새로 제공된 천재(임성숙) K7·K8 PDF로 기존 근거부족 92행을 다시 대조했다. 이 92행은 **일치 66·표현차이 8·수정후보 14·근거부족 4**로 바뀌었고, 기존 362행 기록은 그대로 보존했다.
- 전체 수정후보는 **76행**이다. 교구 누락뿐 아니라 수량·규격·선택 조건·표기, 쪽수, 제목, 성취기준 연결 검토가 섞여 있어 모두 같은 수준의 확정 오류로 보지 않는다. 원본 데이터와 기존 검토표는 수정하지 않았다.
- 전체 근거부족 **5행**은 임성숙 4행과 미래앤 1행이다. 행별로 확인하지 못한 필드와 이유를 남겼다.
- 미래앤 98행은 원문 출판사 `미래앤`과 근거 자료 표기 `미래엔` 차이를 공통 표현차이로 기록했다. 이로 인해 내용상 별도 문제가 없는 행도 결과가 표현차이이며, 수정후보 수와 혼동하지 않아야 한다.

## 전체 판정

- 행 결과: **일치 267 · 표현차이 106 · 수정후보 76 · 근거부족 5 = 454**.
- 출판사별: 천재(정대홍) 96행(일치 82·표현차이 2·수정후보 12), 천재(임성숙) 92행(일치 66·표현차이 8·수정후보 14·근거부족 4), 미래앤 98행(표현차이 84·수정후보 13·근거부족 1), 비상 111행(일치 76·표현차이 11·수정후보 24), 동아 57행(일치 43·표현차이 1·수정후보 13).
- 수정후보 필드: 성취기준 2건, 쪽 3건, 탐구활동 7건, 교구 67건, 합계 79건이다. 한 행에 여러 후보 필드가 있어 행 수는 76이다. 특히 성취기준 2건(`activity_0100`·`0101`)은 공식 문구 오류가 아니라 활동-기준 연결을 내용상 재검토하자는 제안이며, 개별 활동의 명시적 연결표가 없다.
- 근거부족 필드: 쪽 1건, 탐구활동 1건, 교구 5건이다. 이 필드들은 확인된 다른 필드와 구분해 남겼다.

## 대표 후보와 미확인

- 쪽수: 미래엔 `activity_0333`은 122→123쪽, 임성숙 `activity_0389`는 60→61쪽, `activity_0399`는 116→114쪽을 검토한다. 임성숙 K8 `activity_0088`의 108쪽은 108~109쪽 펼침의 시작면이라 단정적 오류 후보로 세지 않았다.
- 제목: 미래엔 `activity_0147`의 `거울가→거울과`, 비상 `activity_0215`의 `물제가→물체가`, 동아 `activity_0289`의 `물잘→물질`, 천재(정대홍) `activity_0005`의 `다른→따른` 등이 있다. 의미가 유지되는 축약·표현 차이는 별도로 구분했다.
- 교구: PDF의 기본 준비물에 있으나 원문이 `null`인 경우, 카드·붙임딱지·물·장치 누락, 수량·규격·농도·선택 조건 생략, 표기 정리 등이 섞여 있다. 임성숙 `activity_0069`는 물 세 조건과 시험관·비커 각 2개, `activity_0071`은 A~D 중 선택하는 조건부 목록, `activity_0104`는 `스마트 기기 혹은 시계`를 검토한다. 교구 후보 67건 모두를 ‘물품 누락’으로 부르지 않는다.
- 임성숙 `activity_0067`은 제공된 K8 PDF에서 원문 활동이 확인되지 않아 다른 활동의 제목·준비물로 대체하지 않았다. `activity_0386`·`0393`·`0094`와 미래엔 `activity_0170`은 학생용 명시적 준비물 목록이 없어 교구 완전성을 미확인으로 남겼다.

## 근거 범위

- 활동명·쪽수·학생용 기본 준비물은 제공된 해당 저자·출판사 PDF의 인쇄면과 물리 PDF 페이지를 대조했다. 위키는 탐색 보조이며, 정대홍 자료를 임성숙 판본의 직접 근거로 쓰지 않았다. 교사용 보충·대안 실험·안전 문구는 기본 준비물 목록과 합치지 않았다.
- 성취기준 문구 확인과 개별 활동에 공식 기준을 배정하는 일은 다르다. 임성숙 K7은 국가교육과정 전사본, K8은 제공 교육과정 PDF의 문구를 비교했다. `activity_0100`·`0101`의 다른 기준 연결은 내용상 추론이며 확정 오류가 아니다. 원문의 내부 단원-순번을 공식 코드로 단정하지 않았다.
- 제공된 임성숙 PDF의 표지·판권지에서 저자와 발행처를 확인했다. 원자료가 작성된 책의 정확한 인쇄 판본 자체는 확인되지 않았다. 사용자 지정 학년 매핑(1~8단원 1학년, 9~15단원 2학년)은 오류 후보로 다루지 않았다.
- 기존 검토표 A:H와 JSON의 일치는 복사·변환 정확성만 의미한다. 기존 I:W 상태를 새 PDF 사실 근거로 쓰거나 수정하지 않았다.
